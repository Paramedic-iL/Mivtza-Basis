# מבצע בסיס

משחק טקטי בעברית — עצור אויבים עם טייזר, טען מחדש, עצור, והגע לנקודת המשימה.

עובד על **מחשב** ועל **טלפון** (כפתורי מגע).

## הרצה

פתח את האתר מ־GitHub Pages, או מקומית:

```bash
python -m http.server 8765
```

ואז גלוש אל `http://localhost:8765`

## שליטה

| מחשב | טלפון |
|------|--------|
| WASD / חצים | כפתורי חיצים |
| Space — טייזר | ⚡ טייזר |
| R — טעינה | R טעינה |
| E — מעצר | 🤝 עצור |

## קבצים

- `index.html` / `style.css` / `game.js` — המשחק
- `assets/player/` — שחקן (למעלה / למטה / שמאלה / ימינה=מראה)
- `assets/sprites/` — אובייקטי מפה ופריטים
- `tools/slice_sprites.py` — חיתוך ספרייטים מהגיליון

אין צורך ב־Google Apps Script.
